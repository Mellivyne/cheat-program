## AI 控制與 AI 玩家

AI 控制頁可連接相容的模型介面，在單人世界執行有界操作；AI 玩家頁可分別管理角色、個性、模型連線與支援的語音設定。連線使用自己的服務商憑據，能力依服務與帳號權限而定。

## 主要功能

**世界內投影**：將應用程式視窗或桌面放進 Minecraft。支援多個螢幕與位置、大小、旋轉、亮度及跟隨方式設定，提供原生解析度、幀率選項及可設定的滑鼠、鍵盤互動。擷取與應用程式互動使用 Windows 原生助手，相容性依應用程式與擷取方式而異。

**空間音訊**：為投影或所選背景應用程式設定世界內音源，依材質與空間近似計算吸收、反射、散射、遮蔽與房間響應。可調整範圍、混響、音量及取樣預算，透過快取更新平衡細節與效能，也可顯示聲線。音訊隔離需要設定虛擬音訊裝置，介面提供設定和狀態檢查。

**粒子特效**：使用真實粒子預覽安排發射點，調整位置、大小與旋轉，並套用直線、圓形、螺旋、八字、波浪或自訂路徑。

**建築匯入**：選取、儲存並預覽建築，匯入其他位置或世界。支援位置與空氣替換設定；伺服器放置需要相應權限。

**配置碼分享**：粒子、建築、模型穿戴及武器動畫各有獨立配置碼，保存對應設定與支援的資源，包括位置、大小、旋轉與動畫細節。匯入前驗證內容及校驗值，設定檔可儲存不同組合。

**更多工具**：音樂與懸浮歌詞、靜態 OBJ／glTF／GLB 模型與玩家皮膚同框預覽、液態玻璃面板、快捷鍵與 HUD 設定、機器人及訓練機器人、聊天工具、裝備與背包整理、容器取物、按鍵顯示、後視鏡、效能趨勢、縮放、時間調整、聲音方向提示與死亡點回收路線。音樂平台功能及音質依服務和帳號權限而定。

## 開始使用

安裝匹配 Minecraft 版本的 Fabric Loader，從 [Releases](https://github.com/Mellivyne/cheat-program/releases) 下載對應 JAR 放進 `mods`。同時只安裝一個匹配版本。以 **Right Shift** 開啟面板，可在設定中改鍵。

1.21.4、1.21.10、1.21.11 使用 Java 21 或更新版本；26.1、26.1.1、26.1.2、26.2 使用 Java 25 或更新版本。首次啟動跟隨系統語言，未支援時使用英文。設定儲存在 `config/cheatprogram-open/`。
