## v1.1 创作更新

建筑预览新增真实 3D 方块材料统计、最大长宽高、逐层剖析与第一人称飞行参观。AI 建筑可使用自己的 API Key，根据文字和参考图生成完整建筑并持续修改。AI 粒子设计可生成原生粒子与运动路径，提供预览及独立 CPS1 配置码。所有 AI 工作区均支持发送图片，图片只发往所选接口，账号凭据及图片不进入分享配置。AI 控制也可用于服务器，并遵循当前玩家的权限。

## AI 控制与 AI 玩家

AI 控制页可连接兼容的模型接口，在单人世界内执行有界操作；AI 玩家页可分别管理角色、性格、模型连接和受支持的语音设置。连接使用自己的服务商凭据，模型能力取决于服务及账号权限。

## 主要功能

**世界内投屏**：将应用窗口或桌面放进 Minecraft，支持多个屏幕以及位置、大小、旋转、亮度和跟随方式设置。提供原生分辨率与帧率选项，以及可配置的鼠标、键盘交互。采集和应用交互使用 Windows 原生助手，兼容性取决于应用和采集方式。

**空间音频**：为投屏或所选后台应用设置世界内音源。根据材质与空间近似计算吸收、反射、散射、遮挡和房间响应；可调整范围、混响、音量与采样预算，使用缓存更新平衡细节和性能，也可显示声线。声音隔离需要配置虚拟音频设备，界面提供设置和状态检查。

**粒子特效**：用真实粒子预览布置发射点，调整位置、缩放和旋转。支持直线、圆形、螺旋、八字、波浪及自定义运动路径。

**建筑导入**：选择、保存和预览建筑，再导入其他位置或世界。支持位置调整与空气替换设置，服务器放置需要相应权限。

**配置码分享**：粒子、建筑、模型穿戴和武器动画各有独立配置码，携带对应设置与受支持的资源，保留位置、大小、旋转和动画细节；导入前验证内容及校验值。配置档可保存不同场景的组合。

**更多工具**：音乐播放器和悬浮歌词、静态 OBJ／glTF／GLB 模型与玩家皮肤同框预览、液态玻璃面板、快捷键和 HUD 自定义、机器人和训练机器人、聊天工具、装备与背包整理、容器取物、按键显示、后视镜、性能趋势、缩放、时间调整、声音方向提示与死亡点回收路线。音乐平台功能及音质取决于服务和账号权限。

## 开始使用

安装匹配 Minecraft 版本的 Fabric Loader，从 [Releases](https://github.com/Mellivyne/cheat-program/releases) 下载对应 JAR 放进 `mods`。同时只安装一个匹配版本。按 **Right Shift** 打开面板，可在设置中改键。

1.20.1、1.20.4、1.21.4、1.21.10、1.21.11 使用 Java 21 或更新版本；26.1、26.1.1、26.1.2、26.2 使用 Java 25 或更新版本。首次启动跟随系统语言，未支持的语言回退到英文。设置保存在 `config/cheatprogram-open/`。
