## AI 操作と AI プレイヤー

互換モデルの接続先を設定し、AI Control からシングルプレイの範囲を限定した操作を指示できます。AI Players ではキャラクター、性格、モデル接続、対応する音声設定を個別に管理します。自分のプロバイダー認証情報を使用し、機能はサービスとアカウントに依存します。

## 主な機能

**画面投影**：アプリのウィンドウやデスクトップを Minecraft 内に配置できます。複数画面の位置、サイズ、回転、明るさを調整し、ワールドへの固定や視点への追従を選べます。ネイティブ解像度・フレームレートの取得とマウス・キーボード設定を備えます。Windows 用ヘルパーを使用し、互換性はアプリと取得方法によって異なります。

**空間音響**：投影中または選択したバックグラウンドアプリを音源にし、材質や空間に応じた吸音、反射、散乱、遮蔽、部屋の応答を近似します。範囲、残響、音量、計算負荷、キャッシュ更新と音線表示を設定できます。元の音の分離には仮想オーディオデバイスが必要で、設定と状態確認を画面から行えます。

**パーティクルと建築**：実際のパーティクルで配置をプレビューし、直線、円、らせん、8の字、波形や独自の経路を設定できます。建築物を選択・保存し、配置をプレビューして別の場所やワールドにインポートできます。サーバーでの配置には権限が必要です。

**設定コード**：パーティクル、建築、装着モデル、武器アニメーションの設定や対応素材を個別に共有できます。位置、サイズ、回転、アニメーションの詳細を保存し、インポート前に内容とチェックサムを検証します。用途別のプロファイルも利用できます。

音楽プレーヤー、浮かぶ歌詞、静的 OBJ・glTF・GLB モデルと自分のスキンの同時プレビュー、液体ガラス風パネル、キー割り当て、HUD、ロボットと練習用ロボット、チャット、装備・インベントリ整理、キー表示、バックミラー、性能グラフ、ズーム、時刻調整、音の方向、死亡地点への回収ルートも用意しています。音楽機能と音質はサービスやアカウント権限に依存します。

## 導入と更新

対応版の Fabric Loader を導入し、[Releases](https://github.com/Mellivyne/cheat-program/releases) の同じ版の JAR を `mods` に入れます。本体 JAR は1つだけ使用します。**Right Shift** でパネルを開き、設定でキーを変更できます。

1.21.4・1.21.10・1.21.11 は Java 21 以降、26.1・26.1.1・26.1.2・26.2 は Java 25 以降が必要です。初回はシステム言語を使用し、未対応なら英語になります。設定先は `config/cheatprogram-open/` です。

互換性、性能、操作性と創作ツールを継続して改善します。各版はビルドを確認し、1.21.4 の画面とプレイヤー／モデルのプレビューはゲーム内でも確認しています。他の版の動作報告も歓迎します。
